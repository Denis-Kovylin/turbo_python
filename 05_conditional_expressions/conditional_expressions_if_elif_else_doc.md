# Python — Conditional Expressions (if, elif, else)

---

## 1. Базовая структура

if условие:  
    # выполняется если условие True  
elif другое_условие:  
    # выполняется если первое False, это True  
else:  
    # выполняется если все условия False  

---

## 2. Операторы сравнения

x == y — равно  
x != y — не равно  
x > y — больше  
x < y — меньше  
x >= y — больше или равно  
x <= y — меньше или равно  

---

## 3. Логические операторы

and — оба условия True  
or — хотя бы одно True  
not — инвертировать условие  

пример:

if x > 0 and x < 10:  
if x == 0 or x == 1:  
if not my_list:  

---

## 4. Проверка вхождения

if item in my_list: — элемент есть в списке  
if item not in my_list: — элемента нет в списке  

---

## 5. Проверка списка на пустоту

if not my_list: — список пустой  
if my_list: — список не пустой  

(предпочтительнее чем len(my_list) == 0)

---

## 6. Перебор списка с условием

for item in my_list:  
    if условие:  
        # действие  
    elif другое_условие:  
        # действие  
    else:  
        # действие  

---

## 7. Проверка списка перед циклом

if not my_list:  
    print('Список пустой')  
else:  
    for item in my_list:  
        # действие  

(всегда проверяй список ДО цикла, не внутри него)

---

## 8. lower() при сравнении строк

'Boss' == 'boss' — False  
'Boss'.lower() == 'boss' — True  

применение:

if new_user.lower() in current_lower:  

---

## 9. Порядок условий

Правило: сначала частные случаи, потом общее правило

if num == 1:  
    print('1st')  
elif num == 2:  
    print('2nd')  
elif num == 3:  
    print('3rd')  
else:  
    print(f'{num}th')  

---

## 10. Частые ошибки

= присваивание, == сравнение  

проверка пустоты ВНУТРИ цикла — цикл не запустится если список пуст:

# НЕПРАВИЛЬНО:
for item in my_list:
    if not my_list:  # никогда не сработает если список пуст

# ПРАВИЛЬНО:
if not my_list:
    print('пусто')
else:
    for item in my_list:

---

## 11. Мини-шпаргалка

равно → ==  
не равно → !=  
оба условия → and  
одно из условий → or  
инверсия → not  
есть в списке → in  
нет в списке → not in  
список пустой → if not my_list  
список не пустой → if my_list  
регистронезависимое сравнение → .lower()
