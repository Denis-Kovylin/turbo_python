# Python — Lists, Tuples, Loops (FOR)

---

## 1. Списки (List)

my_list = [1, 2, 3] — создать список  
empty_list = [] — пустой список  

---

## 2. Кортежи (Tuple)

my_tuple = (1, 2, 3) — создать кортеж  
single_tuple = (1,) — кортеж из одного элемента (запятая обязательна)

tuple нельзя изменять (immutable)

---

## 3. Обращение к элементам

my_list[0] — первый элемент  
my_list[-1] — последний элемент  

my_tuple[0] — доступ к элементу кортежа  

---

## 4. Перебор (for)

for item in my_list: — пройтись по всем элементам  

for item in my_tuple: — работает так же  

---

## 5. range()

range(5) — числа от 0 до 4  

range(1, 5) — от 1 до 4  

range(1, 10, 2) — шаг 2 (1, 3, 5, 7, 9)  

---

## 6. len()

len(my_list) — количество элементов  

---

## 7. min(), max(), sum()

min(my_list) — минимальный элемент  

max(my_list) — максимальный элемент  

sum(my_list) — сумма элементов  

(работает только с числами)

---

## 8. Срезы (slicing)

my_list[0:3] — элементы с 0 по 2  

my_list[:3] — с начала до индекса 2  

my_list[2:] — с индекса 2 до конца  

my_list[:] — копия списка  

my_list[::-1] — перевёрнутый список  

---

## 9. Генерация списков (list comprehension)

[expression for item in list]

пример:

squares = [x**2 for x in range(5)]  
→ [0, 1, 4, 9, 16]

---

## 10. Генерация с условием

[x for x in range(10) if x % 2 == 0]  
→ только чётные числа  

---

## 11. Работа со строками как списком

for letter in "hello": — перебор строки  

---

## 12. enumerate()

for index, item in enumerate(my_list):  
— получить индекс и значение  

---

## 13. zip()

for a, b in zip(list1, list2):  
— перебор двух списков одновременно  

---

## 14. Преобразования

list(tuple) — кортеж → список  

tuple(list) — список → кортеж  

---

## 15. Важные различия

list — изменяемый (mutable)  

tuple — неизменяемый (immutable)  

---

## 16. Частые ошибки

range(5) — это не список, а последовательность  

print(range(5)) — не покажет список  

правильно:

list(range(5))

---

## 17. Мини-шпаргалка

создать список → []  
создать кортеж → ()  
перебор → for  
диапазон → range()  
длина → len()  
мин → min()  
макс → max()  
сумма → sum()  
срез → list[start:end]  
переворот → [::-1]  
генерация → [x for x in ...]  
индексы → enumerate()  
двойной перебор → zip()
