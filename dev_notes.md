# Dev Notes — полезные штуки для разработчика

---

## TODO-комментарии в коде

# TODO — нужно доделать
# FIXME — здесь баг, надо починить
# HACK — работает, но сделано костыльно
# NOTE — важная заметка для читающего код

В PyCharm все TODO и FIXME собираются в одном месте:
View → Tool Windows → TODO

---

## Горячие клавиши PyCharm

F11 — поставить закладку на строку
View → Tool Windows → Bookmarks — открыть список закладок

Alt+7 — структура файла (все функции и классы)

Shift+Shift — поиск по всему проекту (файлы, классы, методы)

Alt+клик — множественный курсор (редактировать несколько строк сразу)

Shift+F6 — переименовать переменную сразу везде в файле

## Отладка (Debug)

🔴 клик на серую полоску слева от номера строки — поставить брейкпоинт
🐛 зелёный жучок рядом с ▶️ — запустить в режиме дебага
F8 — Step Over (следующий шаг)
F7 — Step Into (зайти внутрь функции)
F9 — Continue (продолжить до следующего брейкпоинта)
Панель Variables внизу — значения всех переменных в момент остановки
